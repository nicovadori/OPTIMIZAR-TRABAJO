# Mi Jornada — Android

Proyecto Android nativo de primera versión.

Incluye:
- Tareas diarias
- Prioridades
- Tiempo estimado
- Temporizador Pomodoro configurable por tarea
- Pausa / finalizar
- Marcar tareas completadas
- Limpiar completadas
- Historial persistente con fecha, tiempo estimado y tiempo trabajado
- Datos guardados localmente en el teléfono

## Generar APK
1. Instalar Android Studio.
2. Abrir esta carpeta como proyecto.
3. Esperar a que Gradle sincronice.
4. Ir a Build > Build APK(s).
5. Instalar el APK generado en el teléfono.

El proyecto usa Android SDK 35 y requiere conexión a Internet la primera vez para descargar las herramientas de Gradle.
